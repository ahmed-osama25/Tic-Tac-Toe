# 🎮 Tic Tac Toe — C++

A simple and interactive **Tic Tac Toe** console game built with C++.

This project was created to practice core C++ programming concepts and build a complete console-based application from scratch.

## ✨ Features

- 👥 Two-player mode
- 👤 Custom player names
- ❌ Player X and ⭕ Player O
- 🎯 Choose positions from 1 to 9
- 🛡️ Input validation
- 🚫 Prevents choosing an occupied position
- 🏆 Win detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 Play Again system
- 📜 Rules menu
- 🎨 Colored X and O
- 🧹 Clear console screen
- 🚪 Exit option

## 🎮 How to Play

The board uses numbers from 1 to 9:

     1 | 2 | 3
    -----------
     4 | 5 | 6
    -----------
     7 | 8 | 9

Players take turns choosing an available position.

The first player to get **three symbols in a row** wins.

A winning line can be:

- Horizontal
- Vertical
- Diagonal

If all positions are filled and nobody wins, the game ends in a **draw**.

Shows the number of wins for each player and the total number of draws.
